# Identificação de mini teclados USB programáveis

Comece pelo número de teclas e giratórios, depois confira o VID:PID e a interface HID em **Identificar USB**. Por exemplo, uma pesquisa por `1189:8890 CH57x 3 key knob` é mais específica que pesquisar apenas pelo nome impresso na caixa. O VID:PID pode ser compartilhado por geometrias diferentes.
